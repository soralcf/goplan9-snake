## 2. 全局约定（已约定）

### 2.1 平台与模块

| 项 | 值 |
|---|---|
| 平台 | macOS darwin/arm64（Apple Silicon） |
| Go | 1.27.x；本机 1.27.2 |
| 模块名 | `goplan9snake`（不能带 `-`，否则汇编无法引用跨包符号） |
| 依赖 | 仅标准库和 Go 运行时；无第三方依赖 |
| 汇编 | Go Plan 9 汇编，ABI0；文件名 `*_arm64.s` |

### 2.2 代码边界

产品 Go 文件（非 `*_test.go`）只允许：

- `main` 入口；
- 汇编函数声明（无函数体）；
- 常量（供 `go_asm.h` 使用）；
- `//go:cgo_import_dynamic`。

游戏状态、移动、碰撞、食物生成、寻路、渲染、系统调用必须在 `*_arm64.s`。测试里的 Go oracle 不得进入产品路径。

### 2.3 ABI0 与符号

- 手写汇编用 `TEXT ·Name(SB), NOSPLIT, $frame-argsize`。
- `argsize` 是 ABI0 栈布局后的总大小，包含参数、返回值和返回值区前的对齐填充；以 `go vet` 的 expected 为准。
- 参数名、偏移必须和 Go 声明一致，例如 `a+0(FP)`、`b+8(FP)`；`go vet` 会检查。
- 跨包调用的函数必须导出（大写）；小写符号只在包内可见。
- 包级符号用 `·name(SB)`；无指针 BSS 用 `GLOBL ·name(SB), NOPTR, $bytes`，大小是字节数。
- 不使用 `R18`、`R27`、`R28`、`R29`、`R30`；通用寄存器用 `R0`–`R17`、`R19`–`R26`。
- 需要 Go 常量时 `#include "go_asm.h"`，汇编里写 `const_Name`。

## 3. 数据与编码（已约定，落地时复核）

### 3.1 索引与几何

```text
idx(x, y) = y * W + x
x = idx % W
y = idx / W
N = W * H
```

- 标量尺寸统一用 8 字节槽位；数组元素用 `int32`，偏移 `<<2`。
- 左右移动必须检查列边界，不能只看 `idx` 范围。
- 棋盘几何：

```text
H = rows - 4
H = H - (H % 2)        // 强制偶数
W = (cols - 2) / 2     // 左右边框各 1 列，每格 2 字符
W = min(W, MaxW)
H = min(H, MaxH)
```

- 终端过小时回退到最小尺寸或明确报错，二者在 M4-01 定稿。
- `termSize` 失败时回退 `80×24`。

### 3.2 方向与状态码

| 值 | 方向 | 索引增量 |
|---:|---|---|
| 0 | 上 | `-W` |
| 1 | 右 | `+1` |
| 2 | 下 | `+W` |
| 3 | 左 | `-1` |

| 名称 | 值 | 含义 |
|---|---:|---|
| `StatusMoved` | 0 | 普通移动 |
| `StatusAte` | 1 | 吃到食物，长度 +1 |
| `StatusWin` | 2 | 棋盘已满 |
| `StatusDead` | 3 | 撞墙或自撞 |

BFS 邻居顺序固定为：上、右、下、左。

### 3.3 一次 tick 的顺序

```text
next = chooseNext()
if 越界 or 占用(且不是可进入的尾巴): return Dead
willEat = (next == food)

if willEat:
    occ[next] = 1
    body[(headSlot+1) % N] = next
    headSlot = (headSlot+1) % N
    length += 1
    if length == N: return Win
    food = spawnFood()
    return Ate
else:
    occ[body[tailSlot]] = 0          // 尾巴先让开
    tailSlot = (tailSlot+1) % N
    body[(headSlot+1) % N] = next
    headSlot = (headSlot+1) % N
    return Moved
```

关键点：

- 普通移动必须先清尾巴，再写新头；“新头正好是尾巴格”才合法。
- 吃食物时尾巴不动。
- `length == N` 后停止移动和生成食物。

### 3.4 BSS 布局（M3-01 落地时复核）

| 符号 | 元素大小 | 大小 | 用途 |
|---|---:|---:|---|
| `·occ` | 1 | `MaxCells` | 占用位图 |
| `·body` | 4 | `MaxCells*4` | 环缓冲，存格索引 |
| `·cycleNext` | 4 | `MaxCells*4` | Hamiltonian 环后继 |
| `·cyclePos` | 4 | `MaxCells*4` | 格在环上的位置 |
| `·bfsQueue` | 4 | `MaxCells*4` | BFS 队列 |
| `·bfsFirst` | 4 | `MaxCells*4` | 每格的第一步 |
| `·bfsStamp` | 4 | `MaxCells*4` | 访问代 |
| `·frame` | 1 | 约 1 MiB | 帧缓冲 |

| 符号 | 大小 | 用途 |
|---|---:|---|
| `·gameW`、`·gameH`、`·gameN` | 8 | 当前棋盘尺寸 |
| `·headSlot`、`·tailSlot`、`·length` | 8 | 环缓冲槽位/长度 |
| `·food` | 8 | 食物格；`-1` 表示无 |
| `·rngState` | 8 | xorshift64 状态 |
| `·status` | 8 | 最近状态码 |
| `·ticks` | 8 | tick 计数 |
| `·foodEaten` | 8 | 吃到的食物数 |
| `·winsize` | 8 | `struct winsize`（4 个 `uint16`） |
| `·termRows`、`·termCols` | 8 | 终端尺寸 |
| `·frameLen` | 8 | 当前帧字节数 |
| `·visitedStamp` | 8 | 当前 BFS 代 |

容量上限：`MaxW = 256`、`MaxH = 128`、`MaxCells = 32768`。

### 3.5 终端序列

| 用途 | 序列 |
|---|---|
| 进入备用屏幕 | `\x1b[?1049h` |
| 离开备用屏幕 | `\x1b[?1049l` |
| 隐藏光标 | `\x1b[?25l` |
| 显示光标 | `\x1b[?25h` |
| 光标归位 | `\x1b[H` |
| 清屏 | `\x1b[2J` |

进入顺序：备用屏幕 → 隐藏光标 → 清屏/归位。退出顺序：显示光标 → 离开备用屏幕。恢复必须在 `sysExit` 之前完成。

## 5. M2 契约草案

> 以下条目在对应会话确认后移入“冻结”；未确认前不要按草案写产品代码。`$帧-参数` 是预期值，最终以 `go vet` 为准。

### 5.1 sysWrite（M2-01）

- 状态：草案
- Go 签名：`func sysWrite(fd int32, buf *byte, n int32) int64`
- 预期 `$0-32`：`fd+0`、`buf+8`、`n+16`、`ret+24`。
- 行为：成功后返回 `n`；`n <= 0` 返回 0 且不访问 `buf`；短写时推进 `buf`、减少 `n`，继续写；`EINTR` 重试；其他错误返回 `-errno`，不单独报告已写入的字节数。
- 未定义：`buf == nil && n > 0`；测试不覆盖。
- 测试：`os.Pipe` 与 Go 侧写入对拍；大缓冲并发读取避免阻塞，并尝试制造短写；坏 fd 断言负 errno；`nil + n == 0`。短写和 `EINTR` 分支难以稳定触发，测试不强制，必须标“未实测”或做手工探针。

### 5.2 sysExit（M2-02）

- 状态：草案
- Go 签名：`func sysExit(code int32)`
- 预期 `$0-4`。
- 行为：`R16 = SYS_EXIT (1)`，`R0 = code`，`SVC $0x80`；不返回，不写 `RET`。
- 不负责：恢复终端。调用前必须由调用方完成 `termRestore`。
- 测试：测试二进制 re-exec 子进程；`TestMain` 检测 `GOPLAN9SNAKE_TEST_EXIT`，命中时直接调用 `sysExit`；父进程断言退出码 7、无额外输出。

### 5.3 sleepUS（M2-03）

- 状态：草案
- Go 签名：`func sleepUS(usec int32)`
- 预期 `$0-4`。
- 依赖：Go 文件里的 `//go:cgo_import_dynamic libc_usleep usleep "/usr/lib/libSystem.B.dylib"`。
- 行为：`usec <= 0` 立即返回；否则按 `chunk = min(remaining, 5000)` 循环 `BL libc_usleep(SB)`，忽略单次返回 -1；总时长为近似值，被信号频繁打断时可能略短。
- 测试：`0`/负数快速返回；`120000` 实测在 90–300ms；不测精确分片次数。

### 5.4 sysIoctl（M2-04）

- 状态：草案
- Go 签名：`func sysIoctl(fd int32, req uint64, arg *byte) int32`
- 预期 `$0-28`：`fd+0`、`req+8`、`arg+16`、`ret+24`。
- 行为：`R16 = SYS_IOCTL (54)`，`R0 = fd`，`R1 = req`，`R2 = arg`；成功返回 0；失败返回正 errno（carry 置位时 `R0`）。
- 测试：管道 fd + `TIOCGWINSZ` 断言非零 errno（macOS 预期 `ENOTTY (25)`）；已关闭 fd 断言 `EBADF (9)`。

### 5.5 termSize（M2-05）

- 状态：草案
- Go 签名：`func termSize() int64`
- 预期 `$0-8`。
- 行为：对 fd 1 调 `TIOCGWINSZ`，参数指向 8 字节 BSS `winsize`（4 个 `uint16`）；成功返回 `rows<<32 | cols`；失败或任一维为 0 时回退 `24<<32 | 80`。
- 测试：`go test` 非 tty 断言回退值；pty 下用 `script` 设 40×120，断言 `40<<32 | 120`。

### 5.6 termEnter / termRestore（M2-06）

- 状态：草案
- Go 签名：`func termEnter(fd int32)`、`func termRestore(fd int32)`
- 预期各 `$0-4`。
- 行为：内部走 `sysWrite`。`termEnter` 依次写 `\x1b[?1049h\x1b[?25l\x1b[H\x1b[2J`；`termRestore` 依次写 `\x1b[?25h\x1b[?1049l`。失败忽略，不返回错误；生产调用传 fd 1。
- 测试：`os.Pipe` 捕获字节，逐字节比较两条序列。

### 5.7 Run 终端探针（M2-07）

- 状态：草案
- Go 签名：`func Run()`（默认放在 `internal/term`，由 `main.go` 调用；见 §6）
- 预期 `$0-0`。
- 行为：`termSize` → `termEnter(1)` → 写固定横幅 → `sleepUS(300000)` → `termRestore(1)` → `sysExit(0)`；不解析参数。
- 测试：`manual`，真实终端观察备用屏幕、横幅、光标和主屏幕恢复。

## 6. 开放决策

| 决策点 | 候选/默认 | 影响 | 何时定 |
|---|---|---|---|
| M2 包名 | `internal/term`（默认） vs `internal/sys` 分包 | winsize BSS 与 `termSize` 是否同包 | M2-01 开工前 |
| M2 探针归属 | `internal/term.Run()`（默认） vs `package main` 的 `run()` + 导出终端函数 | 跨包调用、M4 主循环放哪 | M2-07 契约确认 |
| `sysWrite` 错误返回 | `int64` + 负 errno（默认） vs `(n, err)` 多返回值 | ABI0 参数大小、Go 调用侧拆包 | M2-01 契约确认 |
| `termEnter/Restore` 错误传播 | 忽略（默认） vs 返回 `int64` | 终端恢复失败是否可上报 | M2-06 契约确认 |
| M3 方向编码 | 0 上、1 右、2 下、3 左（DESIGN 建议） | 测试注入、BFS 邻居顺序 | M3-01 契约确认 |
| M3 状态码 | 0 Moved、1 Ate、2 Win、3 Dead（DESIGN 建议） | 主循环分支、常量导出 | M3-01 契约确认 |
| M3 初始蛇 | 长度 1，头尾 `(0,0)` | 环序区间和尾巴特例 | M3-02 契约确认 |
| M4 最小终端尺寸 | 20×10 回退 vs 明确报错 | 启动行为、帧缓冲容量 | M4-01 契约确认 |
| M8 Ctrl-C 清理 | 接受限制并文档说明 vs libc `sigaction` vs Go 信号辅助 | 终端残留、代码边界 | M8-01 契约确认 |
| M8 参数解析 | 不做 vs `--seed`/`--size` | 产品 Go 边界、汇编参数传递 | M8-02 契约确认 |
